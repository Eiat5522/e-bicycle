# Glide Monorepo

Monorepo scaffold for the Glide e-bike rental platform.

## Workspaces

- `apps/mobile`: Expo + React Native customer app
- `apps/web`: Next.js admin shell
- `packages/api`: typed mock services and service contracts
- `packages/shared`: shared domain models and utilities

## Commands

- `pnpm dev`
- `pnpm build`
- `pnpm lint`
- `pnpm test`
- `pnpm typecheck`
